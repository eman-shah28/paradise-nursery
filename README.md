# Paradise Nursery Shopping Application

## Project Name

Paradise Nursery Shopping Application

## Project Description

Paradise Nursery is a React-based online plant shopping application.

The application allows users to browse plants, view plant information, add products to a shopping cart, and manage cart quantities.

## Technologies Used

- React
- Vite
- Redux Toolkit
- React Redux
- React Router DOM
- JavaScript
- HTML
- CSS

## Features

- Paradise Nursery landing page
- Company name and Get Started button
- Navigation bar
- Home page
- Plants page
- Shopping Cart page
- About Us page
- Three plant categories
- Six plants per category
- Plant thumbnails
- Plant names
- Plant descriptions
- Plant prices
- Add to Cart functionality
- Disabled Add to Cart button after adding
- Dynamic cart count
- Increase quantity
- Decrease quantity
- Delete cart items
- Individual item total
- Overall cart total
- Checkout Coming Soon message
- Continue Shopping functionality
